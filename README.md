# Trade-Ahead
Unsupervised learning - This project aims to optimize Trade&amp;Ahead's client portfolios by clustering stocks with similar characteristics based on price and financial indicators. This approach helps create diversified portfolios that balance risk and return, enhancing investment performance while mitigating potential losses.
